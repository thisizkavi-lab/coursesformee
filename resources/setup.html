⚙️ Python Setup Guide

Get your computer ready for CS106A: installing Python 3, configuring professional code editors, and using the command line.

📌 Requirements

You will need a computer running macOS (10.15+), Windows (10/11), or Linux (Ubuntu/Debian/Fedora). Chromebooks and iPad tablets can also run Python using cloud environments like Google Colab or Replit.

1 Installing Python 3

CS106A uses modern Python 3 (version 3.10, 3.11, or 3.12). Follow the instructions for your operating system:

🍎 macOS

1. Visit python.org/downloads and download the macOS 64-bit installer.

2. Run the .pkg installer and click through the prompts.

3. Open Terminal (Press Cmd+Space, type Terminal, press Enter) and verify: 

python3 --version

🪟 Windows

1. Visit python.org/downloads and download the Windows installer.

2. Crucial: Check the box that says "Add python.exe to PATH" before clicking Install Now!

3. Open Command Prompt or PowerShell and verify: 

python --version

🐧 Linux

Python 3 comes pre-installed on most modern Linux distributions. On Debian/Ubuntu systems, install the latest tools using apt: 

sudo apt update
sudo apt install python3 python3-pip python3-venv

2 Choosing & Installing an Editor (IDE)

An IDE (Integrated Development Environment) gives you syntax highlighting, auto-completion, error indicators, and a built-in terminal. Stanford CS106A recommends either PyCharm Community Edition or Visual Studio Code. Both are completely free.

3 Running Your First Python Program

Create a new file named hello.py on your computer and type the following code:

Python (hello.py) 
def main():
    print("Welcome to CS106A!")
    name = input("What is your name? ")
    print(f"Hello, {name}! Ready to write some code? 🚀")

if __name__ == "__main__":
    main()

To run this program, open your command-line terminal, navigate to the folder where you saved hello.py, and type:

Terminal / Command Prompt
$ python3 hello.py
Welcome to CS106A!
What is your name? Karel
Hello, Karel! Ready to write some code? 🚀

4 Essential Terminal / Command Line Cheat Sheet

As a programmer, navigating directories via the terminal is a core daily skill. Here are the 5 commands you will use most often:

Mac / Linux Windows (PowerShell) Description
pwd pwd or echo %cd% Print Working Directory: Shows full path of current folder.
ls dir or ls List: Displays all files and subfolders in current folder.
cd foldername cd foldername Change Directory: Enters a specific subfolder.
cd .. cd .. Go Up: Moves one directory level up towards parent folder.
python3 script.py python script.py Run Script: Executes the specified Python program.
python3 -i script.py python -i script.py Interactive Mode: Runs the script and keeps interactive REPL open.

5 Installing Libraries with pip

Python's package manager, pip, allows you to install thousands of community-built libraries from the Python Package Index (PyPI).

Terminal 
# Install standard utilities
pip install requests pillow pytest

# Install the CME193 Scientific Python & Machine Learning Stack
pip install numpy scipy pandas matplotlib scikit-learn
pip install torch torchvision
pip install jupyterlab
💡 Virtual Environments (Best Practice)

When working on multiple Python projects, use virtual environments to keep each project's dependencies isolated: 

python3 -m venv myenv       # 1. Create a virtual environment folder
source myenv/bin/activate   # 2. Activate on macOS/Linux (on Windows: myenv\Scripts\activate)
pip install requests        # 3. Packages install inside myenv only!
deactivate                  # 4. Exit virtual environment when done
