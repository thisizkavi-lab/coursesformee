Chapter 05: Scientific Optimization & Differential Equations

1. SciPy Subpackage Architecture

While NumPy provides fast array operations, SciPy builds on top of it to provide higher-level numerical routines. SciPy is organized into subpackages covering specific scientific domains:

  • scipy.optimize: Root finding, minimization, and curve fitting.
  • scipy.integrate: Quadrature and Ordinary Differential Equations (ODEs).
  • scipy.interpolate: Splines and grid interpolation.
  • scipy.stats: Continuous/discrete distributions and statistical tests.
  • scipy.linalg: Advanced linear algebra (extending numpy.linalg).
SciPy Ecosystem Layering

2. Mathematical Optimization

Optimization is the process of finding the inputs to a function that result in its minimum (or maximum) value.

python 
from scipy.optimize import minimize
import numpy as np

# Rosenbrock function: a classic non-convex optimization test
def rosenbrock(x):
    return (1 - x[0])**2 + 100 * (x[1] - x[0]**2)**2

# Minimize using the BFGS algorithm
initial_guess = np.array([0.0, 0.0])
result = minimize(rosenbrock, initial_guess, method='BFGS')
print(f"Minimum at: {result.x}")

3. Non-linear Parametric Curve Fitting

In the physical sciences, we often want to fit a theoretical mathematical model to noisy experimental data using curve_fit().

python 
from scipy.optimize import curve_fit

# 1. Define the model
def decaying_sine(t, A, gamma, omega):
    return A * np.exp(-gamma * t) * np.cos(omega * t)

# 2. Fit to data (t_data, y_data)
popt, pcov = curve_fit(decaying_sine, t_data, y_data)

4. Numerical Integration

For integrating mathematical functions over a definite interval, SciPy provides quad() (adaptive quadrature).

python 
from scipy.integrate import quad

def integrand(x):
    return np.exp(-x**2)

# Integrate from 0 to infinity
integral, error = quad(integrand, 0, np.inf)

5. Ordinary Differential Equations (ODEs)

To simulate dynamical systems over time (e.g., pendulums, chemical kinetics, population dynamics), we solve Initial Value Problems (IVPs) using solve_ivp().

Deep Dive: The State Vector When solving ODEs in SciPy, you must rewrite higher-order ODEs as a system of first-order ODEs. The state vector $y$ contains all dependent variables. The ODE function must accept (t, y) and return the derivative dy/dt.
python 
from scipy.integrate import solve_ivp

# Lotka-Volterra (Predator-Prey)
def lotka_volterra(t, z, alpha, beta, delta, gamma):
    x, y = z # x: prey, y: predators
    dxdt = alpha * x - beta * x * y
    dydt = delta * x * y - gamma * y
    return [dxdt, dydt]

# Solve from t=0 to t=15
sol = solve_ivp(lotka_volterra, [0, 15], y0=[10, 5], args=(1.5, 1, 1, 3), dense_output=True)

Exercise 1: Root Finding

Use scipy.optimize.root_scalar to find the root of the equation $f(x) = x^3 - 2x - 5$ in the interval [2, 3].

Reveal Step-by-Step Solution
python 
from scipy.optimize import root_scalar
def f(x):
    return x**3 - 2*x - 5

result = root_scalar(f, bracket=[2, 3], method='brentq')
print("Root:", result.root)
