Chapter 02: High-Performance Numerical Computing with NumPy

11.1 The ndarray Architecture

At the core of NumPy is the ndarray (N-dimensional array). Unlike Python lists, ndarrays store uniform data in contiguous memory blocks, characterized by dtype, shape, and strides.

Memory Buffer: [ 1, 2, 3, 4, 5, 6 ]
Shape: (2, 3)
Strides: (12 bytes, 4 bytes) -- assuming int32 (4 bytes per item)
Yields View:
[[1, 2, 3],
 [4, 5, 6]]

11.2 The Universal Broadcasting Rules

Broadcasting allows arithmetic operations between arrays of different shapes without explicit data copying.

The Two Rules of Broadcasting:
  1. If arrays differ in rank, prepend the shape of the lower rank array with 1s.
  2. Dimensions are compatible if they are equal, or if one of them is 1. (The dimension of size 1 is "stretched" to match).
python 
import numpy as np
matrix = np.ones((3, 3))
vector = np.array([1, 2, 3])
print(matrix + vector) # Broadcasts vector across rows
[[2. 3. 4.] [2. 3. 4.] [2. 3. 4.]]

11.3 Boolean Masking & Filtering

Advanced indexing lets you filter arrays efficiently using boolean conditions.

python 
arr = np.array([10, -5, 20, -2, 7])
mask = arr > 0
print(arr[mask])
[10 20 7]

11.4 Multi-Axis Reductions

Operations like np.sum or np.max can collapse dimensions across specified axes.

python 
grid = np.array([[1, 2], [3, 4]])
print(np.sum(grid, axis=0)) # Sum down the columns
[4 6]
