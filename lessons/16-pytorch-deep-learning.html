Chapter 07: Modern Deep Learning Foundations with PyTorch

1. PyTorch Tensor Mechanics

PyTorch sits at the intersection of NumPy's numerical agility and hardware acceleration (GPUs). The core abstraction is the Tensor, which looks identical to an ndarray but has superpowers: it tracks mathematical operations to automatically compute derivatives.

NumPy vs PyTorch Architecture
CPU [ RAM ] -> np.ndarray (CPU limited)
GPU/MPS [ VRAM ] -> torch.Tensor (Massively parallelized, Autograd-enabled)

2. Automatic Differentiation (Autograd)

Backpropagation is the engine of Deep Learning. PyTorch's Autograd builds a dynamic computational graph on the fly as you perform tensor operations.

python
import torch

# require_grad=True tells PyTorch to track operations on x
x = torch.tensor([2.0], requires_grad=True)
y = x ** 2 + 5 * x

# Compute derivatives
y.backward()
print(x.grad) # dy/dx at x=2.0 is 2*x + 5 = 9.0

3. Constructing Neural Networks with torch.nn

We build neural networks by subclassing torch.nn.Module. Layers are initialized in __init__, and the forward pass logic goes in forward().

python
import torch.nn as nn

class SimpleMLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super().__init__()
        self.layer1 = nn.Linear(input_dim, hidden_dim)
        self.relu = nn.ReLU()
        self.layer2 = nn.Linear(hidden_dim, output_dim)
        
    def forward(self, x):
        x = self.layer1(x)
        x = self.relu(x)
        x = self.layer2(x)
        return x

model = SimpleMLP(2, 16, 1)

4. The Canonical 5-Step Training Loop

Unlike Scikit-Learn's one-line fit(), PyTorch requires you to write the optimization loop explicitly. This gives you total control over the learning process.

The 5 Steps of Training: 1. Zero Gradients: Clear old gradients from the last step. 2. Forward Pass: Compute predictions. 3. Loss: Calculate the error. 4. Backward Pass: Compute the gradients (backpropagation). 5. Optimizer Step: Update the network's weights.
python
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
criterion = nn.BCEWithLogitsLoss()

# The Epoch Loop
for epoch in range(100):
    model.train()
    
    # 1. Zero gradients
    optimizer.zero_grad()
    
    # 2. Forward pass

    # 3. Calculate Loss
    loss = criterion(y_pred, y_batch)
    
    # 4. Backpropagation
    loss.backward()
    
    # 5. Parameter update
    optimizer.step()

5. Scalable Data Pipelines (DataLoaders)

For large datasets, we cannot load everything into RAM. PyTorch uses Dataset and DataLoader to yield shuffled mini-batches dynamically.

Write a PyTorch nn.Module for a 3-layer neural network using nn.Sequential inside the __init__ block.

python
class DeepMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(10, 64),
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 2)
        )
    def forward(self, x):
        return self.net(x)
