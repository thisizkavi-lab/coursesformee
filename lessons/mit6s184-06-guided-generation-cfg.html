Chapter 06: Guided Generation & Classifier-Free Guidance (CFG)

Conditional Generative Modeling

To control what a generative model creates, we condition generation on some context $c$ (e.g., text, classes), modeling $p(x|c)$. By Bayes' rule on scores, we have: $$\nabla_x \log p_t(x|c) = \nabla_x \log p_t(x) + \nabla_x \log p_t(c|x)$$ This formulation led to Classifier Guidance, using a pre-trained noisy classifier to guide the unconditional score.

Classifier-Free Guidance (CFG)

Jonathan Ho and Tim Salimans introduced Classifier-Free Guidance (CFG) to eliminate the need for a separate classifier. Instead, the model is trained jointly for conditional and unconditional generation. During training, we drop the condition (replacing it with a null token $c = \emptyset$) with some probability $p_{\text{uncond}} \approx 10\%-20\%$.

During inference, we extrapolate between the unconditional and conditional predictions. For flow matching / diffusion, the guided vector field $\tilde{v}_t$ is: $$\tilde{v}_t(x, c) = v_t(x, \emptyset) + w(v_t(x, c) - v_t(x, \emptyset))$$ where $w > 1$ is the guidance scale. This yields a strong trade-off between sample quality/fidelity (lower FID) and diversity.

Note: Very high guidance scales $w$ can push samples out of distribution. Dynamic thresholding and clip guidance are techniques to mitigate this.

Code: Classifier-Free Guidance in PyTorch

python

import torch

def cfg_sample_step(model, x_t, t, c, w=3.0):
    """
    Performs a single step of CFG prediction for vector field.
    w: guidance scale (typically > 1.0)
    """
    # Batch size
    B = x_t.shape[0]
    
    # Create batched inputs for parallel execution of conditional and unconditional
    # [x_t, x_t]
    x_in = torch.cat([x_t, x_t], dim=0)
    t_in = torch.cat([t, t], dim=0)
    
    # Null condition (e.g., zero tensor or specific learned embedding)
    c_null = torch.zeros_like(c)
    c_in = torch.cat([c, c_null], dim=0)
    
    # Forward pass
    v_pred = model(x_in, t_in, c_in)
    
    # Split predictions
    v_cond, v_uncond = torch.chunk(v_pred, 2, dim=0)
    
    # Apply CFG formula
    v_guided = v_uncond + w * (v_cond - v_uncond)
    
    return v_guided

Exercise 1: Implement Dynamic Thresholding

High CFG scales can cause values to exceed the valid range [-1, 1]. Implement dynamic thresholding on the predicted data to scale it back safely.

def dynamic_thresholding(x_pred, p=0.99):
    s = torch.quantile(torch.abs(x_pred.view(x_pred.size(0), -1)), p, dim=1)
    s = torch.clamp(s, min=1.0)
    s = s.view(-1, 1, 1, 1) # reshape for images
    return torch.clamp(x_pred, -s, s) / s
