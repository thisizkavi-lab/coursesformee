Chapter 03: Core Workflows: Classification, Regression & Generalization

End-to-End Workflows

The standard supervised learning workflows are:

  • Binary Classification: One output node with Sigmoid activation. Binary Crossentropy loss.
  • Multiclass Single-Label Classification: N output nodes with Softmax activation. Categorical Crossentropy loss.
  • Scalar Regression: One output node with Linear activation. Mean Squared Error (MSE) loss.

Generalization vs Overfitting

A model's primary goal is to generalize to unseen data, not just memorize the training set. Techniques to prevent overfitting include:

  • Weight Decay (L1/L2 Regularization): Constraining model complexity.
  • Dropout: Randomly zeroing out activation units during training.
  • Early Stopping: Halting training when validation loss degrades.
python 
import keras
from keras import layers, callbacks

# A robust multiclass classifier with regularization
def build_model(num_classes):
    inputs = keras.Input(shape=(10000,))
    x = layers.Dense(64, activation="relu", kernel_regularizer=keras.regularizers.l2(0.001))(inputs)
    x = layers.Dropout(0.5)(x)
    x = layers.Dense(64, activation="relu", kernel_regularizer=keras.regularizers.l2(0.001))(x)
    x = layers.Dropout(0.5)(x)
    outputs = layers.Dense(num_classes, activation="softmax")(x)
    
    model = keras.Model(inputs, outputs)
    
    # Custom Learning Rate Schedule
    lr_schedule = keras.optimizers.schedules.ExponentialDecay(
        initial_learning_rate=1e-3,
        decay_steps=1000,
        decay_rate=0.9
    )
    
    model.compile(optimizer=keras.optimizers.Adam(learning_rate=lr_schedule),
                  loss="categorical_crossentropy",
                  metrics=["accuracy"])
    return model

# Early stopping callback
early_stopping = callbacks.EarlyStopping(monitor='val_loss', patience=3, restore_best_weights=True)
