Chapter 06: Multi-Dimensional Data & Image Processing

2D Grids as Lists of Lists

To represent 2-dimensional spaces, we use lists of lists. This is typically done in a row-major order, where the outer list represents rows, and each inner list represents the columns within that row.

grid = [
  [1, 2, 3],  # Row 0
  [4, 5, 6],  # Row 1
  [7, 8, 9]   # Row 2
]

# Accessing row 1, col 2 -> grid[1][2] -> yields 6
Warning: The Reference Trap!
Never create a 2D grid using grid = [[0] * cols] * rows. This creates multiple references to the same inner list. Modifying one row will modify them all! Instead, use a list comprehension: grid = [[0 for _ in range(cols)] for _ in range(rows)].

Digital Image Representation

Digital images are simply grids of pixels. Each pixel stores color information using the RGB model (Red, Green, Blue). Each channel takes an integer value from 0 to 255.

  • (0, 0, 0): Black
  • (255, 255, 255): White
  • (255, 0, 0): Pure Red

Image Manipulation Algorithms

By iterating over an image grid, we can apply transformations pixel by pixel.

Grayscale Conversion

To convert an image to grayscale, we calculate the luminance of each pixel. Because human eyes are more sensitive to green, we use a weighted average:

python
def to_grayscale(image):
    for y in range(image.height):
        for x in range(image.width):
            pixel = image.get_pixel(x, y)
            luminance = int(pixel.r * 0.299 + pixel.g * 0.587 + pixel.b * 0.114)
            pixel.r = luminance
            pixel.g = luminance
            pixel.b = luminance

Practical Exercises

Exercise 1: Horizontal Flip

Write an algorithm to mirror an image horizontally.

Reveal Step-by-Step Solution
python
def flip_horizontal(image):
    width = image.width
    height = image.height
    for y in range(height):
        for x in range(width // 2):
            left_pixel = image.get_pixel(x, y)
            right_pixel = image.get_pixel(width - 1 - x, y)
            
            # Swap colors
            temp_r, temp_g, temp_b = left_pixel.r, left_pixel.g, left_pixel.b
            
            left_pixel.r, left_pixel.g, left_pixel.b = right_pixel.r, right_pixel.g, right_pixel.b
            right_pixel.r, right_pixel.g, right_pixel.b = temp_r, temp_g, temp_b
