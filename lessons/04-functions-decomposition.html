Chapter 04: Functions, Decomposition & The Call Stack

The Purpose of Functions

Functions allow us to encapsulate complexity, turning blocks of code into abstract, reusable tools (black boxes).

Anatomy of a Function

python 

def calculate_tax(amount, rate=0.08):
    """Calculates tax based on the given rate."""
    return amount * rate

The Runtime Call Stack

When a function is called, a new frame is pushed onto the call stack. This isolates local variables.

|-------------------|
| calculate_tax()   | <- Top Frame (active)
| amount: 100       |
| rate: 0.08        |
|-------------------|
| main()            | <- Bottom Frame
|-------------------|

Parameter Passing Mechanics

Python uses "pass-by-object-reference". The argument's reference is passed to the function's parameter.

Mutable Default Arguments: Never use a mutable object like a list as a default argument, as it is evaluated only once when the function is defined.

Exercise 1: Factorial

Write a function to compute the factorial of n using a loop.

Reveal Step-by-Step Solution
python 

def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result
