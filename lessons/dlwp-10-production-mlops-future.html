Chapter 10: Production Engineering, Multi-GPU Scaling & The Future of AI

1. The Scale of Modern ML

Training large models requires moving from a single GPU to multi-node clusters. Concepts like Data Parallelism, Model Parallelism, and Mixed Precision are essential tools for a Deep Learning Engineer.

Mixed Precision: FP16 halves the memory footprint but risks underflow. Loss scaling is typically needed to preserve small gradient values.

2. Code Walkthrough: Distribution in Keras 3


import keras
import tensorflow as tf

# 1. Enable mixed precision
keras.mixed_precision.set_global_policy('mixed_float16')

# 2. Setup Multi-GPU Strategy
strategy = tf.distribute.MirroredStrategy()
print('Number of devices: {}'.format(strategy.num_replicas_in_sync))

# 3. Create model under strategy scope
with strategy.scope():
    inputs = keras.Input(shape=(32, 32, 3))
    x = keras.layers.Conv2D(32, 3, activation="relu")(inputs)
    x = keras.layers.GlobalAveragePooling2D()(x)
    outputs = keras.layers.Dense(10, dtype='float32')(x) # Output as FP32
    
    model = keras.Model(inputs, outputs)
    model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')

Exercise: Limits of Deep Learning

What is the difference between interpolation and extrapolation in the context of neural networks?

Reveal Step-by-Step Solution

Deep learning models excel at interpolating within the convex hull of their training data manifold. They typically fail to extrapolate—to perform logical reasoning in OOD (Out-Of-Distribution) tasks that require genuine abstraction, such as those evaluated by Chollet's ARC dataset.
