Chapter 05: Physics-Based Virtual Screening & Alchemical Free Energy

Reading Time: 45 mins | Part III

Alchemical Free Energy Perturbation (FEP)

Calculating the absolute binding affinity of a drug is computationally prohibitive. Instead, we use thermodynamic cycles to calculate the relative binding affinity between two similar drug candidates by computationally morphing (mutating) one ligand into another—an "alchemical" transformation.

Deep Mental Model: Thermodynamic Cycle (ΔΔG)

        Ligand A (water) --------> Ligand B (water)    : dG_water
             |                          |
             | bind                     | bind
             v                          v
        Ligand A (protein) ------> Ligand B (protein)  : dG_protein

        ddG_bind = dG_protein - dG_water

Algorithmic Implementation: Bennett Acceptance Ratio (BAR)

import numpy as np

def calculate_bar_free_energy(work_A_to_B, work_B_to_A, temperature=300):
    """
    A simplified estimator for the Bennett Acceptance Ratio.
    Calculates the free energy difference dF.
    """
    kB = 0.001987 # kcal/(mol*K)
    beta = 1.0 / (kB * temperature)
    
    # Simple exponential average approximation (Crooks fluctuation theorem)
    exp_A = np.mean(np.exp(-beta * work_A_to_B))
    exp_B = np.mean(np.exp(-beta * work_B_to_A))
    
    dF = - (1/beta) * np.log(exp_A / exp_B)
    return dF

# Simulated work values (kcal/mol) from MD trajectories
w_AB = np.random.normal(5.0, 0.5, 1000)
w_BA = np.random.normal(-5.2, 0.5, 1000)

ddG = calculate_bar_free_energy(w_AB, w_BA)
print(f"Estimated Free Energy Difference: {ddG:.2f} kcal/mol")
