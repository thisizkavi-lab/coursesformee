Chapter 03: Logic, Conditionals & Iteration Invariants

Boolean Algebra & Predicates

Programming logic builds upon Boolean algebra. Expressions evaluate to True or False.

python

x = 5
is_even = (x % 2 == 0) # False

Logical Connectives & Short-Circuiting

Python uses and, or, and not. Short-circuiting means Python stops evaluating as soon as the result is determined.

Short-circuit Safety: Use and to guard against errors, like if x != 0 and 10/x > 2:.

Branching Structures

The if-elif-else ladder creates multi-way decision trees.

python

if temp > 80:
    print("Hot")
elif temp > 60:
    print("Nice")
else:
    print("Cold")

Iteration & Sentinels

while loops continue until a condition breaks. A sentinel value signals the end of input.

LOOP INVARIANT:
Sum always equals the total of all numbers read so far.
[ init ] -> [ check condition ] -> [ body ] -> [ update ] -> (loop)

Exercise 1: Sentinel Loop

Read numbers until the user types -1, then print the sum.

Reveal Step-by-Step Solution
python

total = 0
while True:
    val = int(input("Enter num (-1 to quit): "))
    if val == -1:
        break
    total += val
print("Total:", total)
