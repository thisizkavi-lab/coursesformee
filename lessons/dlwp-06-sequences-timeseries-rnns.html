Chapter 06: Sequential Modeling & Timeseries Forecasting (GRUs/LSTMs)

1. The Challenge of Time

Until now, our models have treated inputs as independent and identically distributed (i.i.d). But what if you are predicting tomorrow's temperature? The order of the days matters. This chapter introduces sequence representation and recurrent neural networks (RNNs).

Timeseries Windowing: To train a neural network on sequences, we typically frame the problem using a sliding window of past observations (lags) to predict future ones.

2. Recurrent Neural Networks (RNNs)

RNNs process sequences by iterating through the elements and maintaining a state containing information relative to what they have seen so far. However, standard RNNs suffer from the vanishing gradient problem.

LSTM Cell Architecture
----------------------
      [c_t-1] --------------------------------------------> [c_t]
         |                                                   |
         v                                                   v
      [f_t] (Forget)  [i_t] (Input)  [o_t] (Output)        [h_t]
         ^               ^              ^                    ^
         |               |              |                    |
[h_t-1] -+---------------+--------------+--------------------+
[x_t] ---+

LSTMs and GRUs solve this using gating mechanisms. The Forget Gate decides what to discard from the cell state, the Input Gate decides what new information to add, and the Output Gate decides what to output as the hidden state.

3. Code Walkthrough: LSTM Forecasting in Keras 3


import keras
import numpy as np

# 1. Generate synthetic timeseries data
time = np.arange(0, 100, 0.1)
data = np.sin(time) + np.random.normal(0, 0.1, len(time))

# 2. Windowing function
def create_windows(series, window_size):
    X, y = [], []
    for i in range(len(series) - window_size):
        X.append(series[i : i + window_size])
        y.append(series[i + window_size])
    return np.array(X)[..., np.newaxis], np.array(y)

X_train, y_train = create_windows(data, window_size=20)

# 3. Build LSTM Model
inputs = keras.Input(shape=(20, 1))
x = keras.layers.LSTM(32)(inputs)
outputs = keras.layers.Dense(1)(x)
model = keras.Model(inputs, outputs)

model.compile(optimizer="adam", loss="mse")
model.fit(X_train, y_train, epochs=5, batch_size=32)
