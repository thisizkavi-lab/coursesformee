Chapter 01: Generative Foundations, ODEs & Stochastic Calculus

Course: MIT 6.S184 | Reading Time: 45 mins | Part: Advanced Generative AI

The Generative Modeling Challenge

In this chapter, we lay the mathematical groundwork for continuous-time generative models. The core challenge in generative modeling is to transform a simple, known distribution (like a standard Gaussian) into a complex, unknown data distribution (like natural images).

Pushforward Measures
A mapping $f: X \to Y$ takes a probability distribution $p_X$ on $X$ and "pushes it forward" to a new distribution $p_Y$ on $Y$, denoted as $f_\# p_X$.

Vector Fields and ODEs

Instead of single mappings, we consider continuous transformations parameterized by time $t \in [0, 1]$. We construct a vector field $v_t(x)$ which defines an Ordinary Differential Equation (ODE):

dx/dt = v_t(x)
x(0) ~ p_0 (Data)  ---- ODE Flow ----> x(1) ~ p_1 (Noise)

Introduction to Stochastic Calculus

When we add random noise to our continuous processes, ODEs become Stochastic Differential Equations (SDEs). A typical SDE looks like:

$dx_t = f(x_t, t)dt + g(t)dW_t$

Here $dW_t$ is the differential of a Wiener process (Brownian motion).

python 
import numpy as np
import matplotlib.pyplot as plt

def euler_maruyama(num_steps=1000, dt=0.01):
    t = np.linspace(0, num_steps*dt, num_steps)
    W = np.zeros(num_steps)
    for i in range(1, num_steps):
        # dW ~ N(0, dt)
        dW = np.random.normal(0, np.sqrt(dt))
        W[i] = W[i-1] + dW
    return t, W

t, W = euler_maruyama()
plt.plot(t, W)
plt.title("1D Brownian Motion")
plt.show()

def euler_maruyama_2d(num_steps=1000, dt=0.01):
    W = np.zeros((num_steps, 2))
    for i in range(1, num_steps):
        dW = np.random.normal(0, np.sqrt(dt), size=2)
        W[i] = W[i-1] + dW
    return W
