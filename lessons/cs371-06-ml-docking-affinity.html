Reading Time: 45 mins | Part III

Equivariant Graph Neural Networks & 3D Grids

To apply deep learning to molecular docking, we must appropriately represent protein-ligand complexes. We can voxelize the complex into 3D grids (e.g., GNINA) or represent them as graphs where atoms are nodes and coordinates act as features (e.g., EquiBind, DiffDock). E(3)-equivariant networks ensure predictions are invariant to rotation and translation.

Deep Mental Model: 3D Grid Representation

Instead of lists of coordinates, consider the space as a 3-dimensional tensor with different channels representing atom types or physicochemical properties (like hydrophobicity).

Input Coordinates:         Voxelized 3D Tensor:
(x1, y1, z1, 'C')   =>     [C_Channel, O_Channel, N_Channel, ...]
(x2, y2, z2, 'O')          Each channel is a 3D grid (e.g., 32x32x32)
                           where value = 1.0 if atom is present.

Algorithmic Implementation: 3D Grid Voxelization

Converting atomic coordinates into multi-channel density tensors for a 3D CNN.

import numpy as np

def voxelize_atoms(coordinates, atom_types, grid_size=32, resolution=1.0):
    """
    Converts atom coordinates to a 3D density grid.
    """
    num_channels = len(set(atom_types))
    grid = np.zeros((num_channels, grid_size, grid_size, grid_size))
    
    # Shift coordinates to center of grid
    center = grid_size * resolution / 2.0
    shifted_coords = coordinates + center
    
    for coord, atype in zip(shifted_coords, atom_types):
        x, y, z = (coord / resolution).astype(int)
        
        if 0 <= x < grid_size and 0 <= y < grid_size and 0 <= z < grid_size:
            grid[atype, x, y, z] += 1.0 # Add density
            
    return grid

coords = np.array([[0, 0, 0], [1.5, 2.0, -1.0]])
types = [0, 1] # 0=Carbon, 1=Oxygen
tensor = voxelize_atoms(coords, types)
print(f"Voxelized Tensor Shape: {tensor.shape}")
print(f"Density at center (Carbon): {tensor[0, 16, 16, 16]}")
