Chapter 05: Sequential Structures: Strings, Lists & Mutability

Sequences in Memory

In Python, a sequence is a contiguously ordered collection of items. Elements in a sequence have a predictable order and can be accessed via numerical indices. The two most prominent sequences are strings (ordered collections of characters) and lists (ordered collections of arbitrary objects).

Memory Address: 0x100      0x104      0x108      0x10C
Index:             0          1          2          3
                +----------+----------+----------+----------+
string "CODE"   |   'C'    |   'O'    |   'D'    |   'E'    |
                +----------+----------+----------+----------+
Index (Neg):      -4         -3         -2         -1

Python utilizes 0-based indexing. The first element is at index 0. It also seamlessly supports negative indexing, where -1 retrieves the last element.

Slicing Syntax & Semantics

Slicing allows you to extract a sub-sequence using the notation seq[start:stop:step]. The slice begins at start (inclusive) and goes up to, but not including, stop (exclusive), stepping by step.

python 
text = "PYTHON"
print(text[1:4])   # 'YTH'
print(text[:3])    # 'PYT' (omitted start defaults to 0)
print(text[3:])    # 'HON' (omitted stop defaults to end)
print(text[::-1])  # 'NOHTYP' (step of -1 reverses the sequence)
Note: Slicing a sequence always creates a new "shallow copy" of that sequence. Modifying the slice does not modify the original sequence (relevant for mutable sequences).

Mutability vs Immutability

This is one of Python's most critical concepts. Strings are immutable. Once a string is created in memory, its characters cannot be changed. Attempting text[0] = 'X' will raise a TypeError. Operations like .upper() or .replace() return new strings.

Lists, however, are mutable. You can alter their elements in place without changing the list's memory address.

python 
# Strings (Immutable)
s = "cat"
s = "b" + s[1:] # Creates a new string "bat", reassigned to s

# Lists (Mutable)
lst = ['c', 'a', 't']
lst[0] = 'b'    # Modifies the list in memory: ['b', 'a', 't']

Python Lists in Depth

Under the hood, Python lists are dynamic arrays. They over-allocate memory to ensure that appending elements is amortized $O(1)$ time complexity. When the underlying array is full, Python allocates a new, larger array and copies the elements over.

  • .append(x): Adds item x to the end.
  • .pop([i]): Removes and returns the item at index i (defaults to last item).
  • .insert(i, x): Inserts x at index i.
  • .extend(iterable): Appends all items from iterable.

Aliasing vs Cloning

Because variables are merely references to objects in memory, assignment creates an alias.

list_a = [1, 2, 3]
list_b = list_a       <-- ALIAS: list_a and list_b point to the SAME object
list_c = list_a[:]    <-- CLONE: list_c points to a NEW list with same contents
python 
list_a = [1, 2, 3]
list_b = list_a
list_b[0] = 99
print(list_a) # Output: [99, 2, 3] (Affected!)

list_c = list_a.copy() # or list_a[:]
list_c[0] = 5
print(list_a) # Output: [99, 2, 3] (Unaffected)

Practical Exercises

Exercise 1: Palindrome Verifier

Write a function is_palindrome(text) that checks if a string is a palindrome, ignoring spaces, punctuation, and capitalization.

Reveal Step-by-Step Solution
python 
def is_palindrome(text):
    # 1. Clean the string
    cleaned = ""
    for char in text:
        if char.isalnum():
            cleaned += char.lower()
    
    # 2. Check if reverse equals the cleaned string
    return cleaned == cleaned[::-1]

print(is_palindrome("A man, a plan, a canal: Panama")) # True
