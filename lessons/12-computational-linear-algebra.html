Chapter 03: Computational Linear Algebra, SVD & Least Squares

12.1 Vectors and Matrices in NumPy

Linear algebra is the mathematical engine of ML. In Python, matrix multiplication is natively supported via the @ operator (syntactic sugar for np.matmul).

python
import numpy as np
A = np.array([[1, 2], [3, 4]])
x = np.array([1, 1])
print(A @ x)
[3 7]

12.2 Solving Linear Systems $Ax = b$

Mathematically, $x = A^{-1}b$. Computationally, explicitly computing the inverse $A^{-1}$ is disastrous for numerical stability. Always use solvers like np.linalg.solve.

Never compute explicit inverse!

Computing an explicit inverse is slower and more prone to floating point errors than LU or Cholesky factorizations used by built-in solvers.

python
x = np.linalg.solve(A, b)

12.3 Singular Value Decomposition (SVD)

SVD factorizes any matrix $A$ into $U \Sigma V^T$. It is the Swiss Army knife of linear algebra, used for PCA, data compression, and pseudo-inverses.

A       =   U       *   Σ       *   V^T
(m x n)     (m x m)     (m x n)     (n x n)
Data        Orthogonal  Diagonal    Orthogonal

Truncating $\Sigma$ to keep only the largest singular values gives an optimal low-rank approximation of the matrix.

12.4 Ordinary Least Squares (OLS)

For overdetermined systems (more equations than unknowns), we want to find $x$ that minimizes $||Ax - b||_2^2$. This is solved via np.linalg.lstsq.
