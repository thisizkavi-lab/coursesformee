Chapter 02: Continuous Normalizing Flows & Conditional Flow Matching

Course: MIT 6.S184 | Reading Time: 50 mins | Part: Advanced Generative AI

Continuous Normalizing Flows

Continuous Normalizing Flows (CNFs) model a probability density over time governed by the continuity equation:

$\partial_t p_t(x) + \nabla \cdot (p_t(x) v_t(x)) = 0$

Intractable Marginal Matching
Directly matching a marginal vector field $v_t(x)$ is generally intractable because we do not have access to the ground-truth marginal probability path.

Conditional Flow Matching (CFM)

Lipman et al. introduced Conditional Flow Matching. We define simple conditional paths between a datapoint $x_1$ and noise $x_0$, such as the linear Gaussian path: $x_t = (1-t)x_0 + t x_1$.

The conditional vector field is $u_t(x|x_1) = x_1 - x_0$.

Noise x_0  ========================> Data x_1
  (Conditional Paths aggregate to Marginal Field)
        
import torch
import torch.nn as nn

def compute_cfm_loss(model, x_1, x_0):
    t = torch.rand(x_1.shape[0], 1)
    # Linear interpolation
    x_t = (1 - t) * x_0 + t * x_1
    # Target vector field
    u_t = x_1 - x_0
    
    # Model prediction
    v_pred = model(x_t, t)
    
    loss = torch.mean((v_pred - u_t) ** 2)
    return loss
