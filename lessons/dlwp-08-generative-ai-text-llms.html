Chapter 08: Generative AI for Text: Causal Decoders & Modern LLMs

1. Autoregressive Generation

Modern LLMs are causal decoders. They predict the next token given all previous tokens. To scale efficiently, techniques like KV-Caching and parameter-efficient fine-tuning (LoRA) are essential.

Sampling Strategies: Use temperature to control randomness, top-k to truncate the vocabulary to the top k tokens, and top-p (nucleus sampling) to truncate to the top percentile of mass.

2. Code Walkthrough: Generating text with temperature


import numpy as np

def sample_with_temperature(logits, temperature=1.0):
    # Scale logits by temperature
    logits = np.array(logits) / temperature
    
    # Softmax to get probabilities
    exp_preds = np.exp(logits)
    preds = exp_preds / np.sum(exp_preds)
    
    # Sample from the resulting distribution
    probas = np.random.multinomial(1, preds, 1)
    return np.argmax(probas)

Exercise: KV Caching Concept

Why do we cache Keys and Values in autoregressive decoding?

Reveal Step-by-Step Solution

Since the previous tokens do not change, their Key and Value projections in the attention mechanism remain constant. Caching them prevents re-computing the matrix multiplications for all prior tokens on every new step.
