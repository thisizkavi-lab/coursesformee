Chapter 04: The Probability Flow ODE, Exact Likelihood & Hutchinson Trace

Course: MIT 6.S184 | Reading Time: 60 mins | Part: Advanced Generative AI

The Probability Flow ODE

Every SDE has a deterministic counterpart called the Probability Flow ODE, which shares the same marginal distributions $p_t(x)$:

$dx = [f(x,t) - \frac{1}{2}g(t)^2 \nabla_x \log p_t(x)]dt$

Exact Likelihood Calculation
Using the instantaneous change of variables, we can compute exact likelihoods using the trace of the Jacobian of the vector field:
$\log p_0(x_0) = \log p_1(x_1) + \int_0^1 \text{Tr}(\nabla_x v_t(x_t)) dt$

Hutchinson Trace Estimator

Computing the exact trace requires $D$ backwards passes for a $D$-dimensional vector field. Instead, we use the Hutchinson trace estimator: $\text{Tr}(J) \approx \mathbb{E}_{v \sim \mathcal{N}(0, I)} [v^T J v]$

import torch

def hutchinson_trace(x, fn):
    # fn is the vector field returning v_t(x_t)
    x.requires_grad_(True)
    v = fn(x)
    
    noise = torch.randn_like(x)
    
    # Vector-Jacobian Product (VJP)
    vjp = torch.autograd.grad(v, x, grad_outputs=noise, create_graph=True)[0]
    
    # Trace estimate is dot product of noise and VJP
    trace = torch.sum(vjp * noise, dim=1)
    return trace
