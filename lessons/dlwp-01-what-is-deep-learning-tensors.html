Chapter 01: What is Deep Learning & Tensor Mathematical Foundations

Representations in AI vs Classical ML

Deep learning is ultimately about representation learning. While classical machine learning requires careful feature engineering (creating representations manually), deep learning models learn hierarchical representations of data automatically.

The Manifold Hypothesis and Crumpled Paper

A useful geometric intuition for deep learning is the "crumpled paper ball" analogy. Imagine two sheets of paper, one red and one blue, crumpled together. The goal of a neural network is to systematically uncrumple this complex, non-linear manifold into a space where the two colors can be separated by a simple linear boundary.

Deep Dive: The Manifold Hypothesis

Real-world high-dimensional data (like images of faces) lies on a low-dimensional manifold embedded in the high-dimensional space. Deep neural networks learn to continuously deform these manifolds into simpler, linearly separable representations.

Tensor Operations and Geometry

Tensors are the fundamental data structures in deep learning. A tensor is a generalization of scalars (0D), vectors (1D), and matrices (2D) to arbitrary dimensions.

0D Tensor: 5 (Scalar)
1D Tensor: [1, 2, 3] (Vector)
2D Tensor: [[1, 2], [3, 4]] (Matrix)
3D Tensor: [[[...]]] (e.g., Image with height, width, channels)
4D Tensor: [[[[...]]]] (e.g., Video: batch, frames, height, width, channels)

Broadcasting Rules

Broadcasting allows tensor operations on arrays with different shapes. Smaller tensors are "broadcast" (virtually copied) to match the shape of the larger tensor.

Gradient-Based Optimization from Scratch

Training a neural network involves minimizing a loss function by adjusting weights using gradients. Backpropagation computes these gradients efficiently using the chain rule.

python 
import numpy as np

# A simple 2-layer neural network trained via SGD from scratch
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    return x * (1 - x)

# Data: XOR problem
X = np.array([[0,0], [0,1], [1,0], [1,1]])
y = np.array([[0], [1], [1], [0]])

np.random.seed(42)
weights0 = 2 * np.random.random((2, 4)) - 1
weights1 = 2 * np.random.random((4, 1)) - 1
learning_rate = 0.1

for epoch in range(10000):
    # Forward Pass
    layer0 = X
    layer1 = sigmoid(np.dot(layer0, weights0))
    layer2 = sigmoid(np.dot(layer1, weights1))
    
    # Loss computation (Mean Squared Error)
    layer2_error = y - layer2
    
    if (epoch % 5000) == 0:
        print(f"Error at epoch {epoch}: {np.mean(np.abs(layer2_error))}")
        
    # Backward Pass
    layer2_delta = layer2_error * sigmoid_derivative(layer2)
    layer1_error = layer2_delta.dot(weights1.T)
    layer1_delta = layer1_error * sigmoid_derivative(layer1)
    
    # Update Weights (SGD)
    weights1 += layer1.T.dot(layer2_delta) * learning_rate
    weights0 += layer0.T.dot(layer1_delta) * learning_rate

print("Final Predictions:\n", layer2)
