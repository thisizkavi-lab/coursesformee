Chapter 09: Algorithms, Search Engines, Web APIs & Ethics

9.1 Custom Sorting in Python

Sorting data efficiently is fundamental in computer science. Python provides two built-in mechanisms for sorting: the sorted() function and the in-place .sort() list method.

In-Place vs. New Object

my_list.sort() modifies the list directly and returns None (in-place operation), while sorted(my_iterable) creates and returns a brand-new list without modifying the original data.

The key= Parameter and Lambda Expressions

Often, we need to sort complex objects. Python’s sorting functions accept a key parameter—a function that extracts a comparison key from each element.

python 
students = [('Alice', 88), ('Bob', 95), ('Charlie', 72)]
# Sort by score (the second element in the tuple)
sorted_students = sorted(students, key=lambda student: student[1])
print(sorted_students)
[('Charlie', 72), ('Alice', 88), ('Bob', 95)]

9.2 Information Retrieval & Search Engines

Search engines process vast collections of text to instantly find documents matching user queries. This requires transforming natural language into structured data.

Forward vs. Inverted Indices

A Forward Index maps documents to the words they contain. It's easy to build but terribly slow for search, requiring scanning every document. An Inverted Index reverses this mapping: it maps words to the documents that contain them.

Forward Index (Doc -> Words)        Inverted Index (Word -> Docs)
Doc1: [apple, banana, apple]  ==>   apple:  [Doc1, Doc2]
Doc2: [apple, cherry]               banana: [Doc1]
                                    cherry: [Doc2]

Query Execution (Boolean Intersections)

When searching for multiple terms like "apple AND banana", the search engine simply computes the set intersection of the document lists for "apple" and "banana".

9.3 Client-Server Architecture & The Internet

The web operates on the client-server model, utilizing a hierarchy of protocols to ensure reliable communication across a decentralized network.

HTTP and REST APIs

HyperText Transfer Protocol (HTTP) is the language of the web. Modern systems interact via APIs using formats like JSON (JavaScript Object Notation).

python 
import json
import urllib.request

url = "https://api.github.com/users/octocat"
response = urllib.request.urlopen(url)
data = json.loads(response.read().decode('utf-8'))
print(data["name"])

9.4 Ethics in Computing

Code is not neutral. As software engineers, our systems impact millions of lives. Algorithmic bias occurs when models perpetuate historical discrimination, often through proxy variables (e.g., zip codes proxying for race).

Facial Recognition Disparities

Studies (like the Gender Shades project) have shown massive demographic disparities in facial recognition systems, with significantly higher error rates for darker-skinned females due to unrepresentative training data.
