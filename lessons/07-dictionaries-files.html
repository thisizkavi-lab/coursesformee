Chapter 07: Associative Arrays: Hash Maps, Dicts & Files

Dictionaries & Hash Maps

While lists find elements by numerical index (offset), dictionaries (hash maps) find elements via unique keys. This transforms an $O(N)$ scan operation into a highly efficient $O(1)$ lookup via hashing.

Hash Function Process:
"apple" --(hash_func)--> 425178 --(mod)--> Index 3
                                          [ ... ]
                                          [ 3: "red" ]
                                          [ ... ]

Rules:

  • Keys must be immutable (strings, integers, tuples).
  • Values can be anything, including lists or other dictionaries.

Dictionary Operations

You interact with dictionaries primarily through key indexing, similar to lists.

python
counts = {}
counts["apple"] = 1       # Add
counts["apple"] += 1      # Update
val = counts.get("banana", 0) # Safe lookup (returns 0 if not found)

Iteration uses `.keys()`, `.values()`, or `.items()`.

python
for key, value in counts.items():
    print(f"{key}: {value}")

File Streams & Persistence

To read data from disk into memory, we use the open() function inside a with context manager, which guarantees the file stream is safely closed when we are done.

python
with open('data.csv', 'r') as file:
    for line in file:
        line = line.strip() # Remove trailing newline
        parts = line.split(',')
        print(parts)

Practical Exercises

Exercise 1: Word Frequency Counter

Read a file and build a dictionary counting occurrences of each word.

Reveal Step-by-Step Solution
python
def word_frequencies(filename):
    counts = {}
    with open(filename, 'r') as f:
        for line in f:
            words = line.strip().split()
            for w in words:
                w = w.lower()
                counts[w] = counts.get(w, 0) + 1
    return counts
