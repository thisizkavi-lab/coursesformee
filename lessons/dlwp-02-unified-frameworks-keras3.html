Chapter 02: The Multi-Backend Paradigm: TensorFlow, PyTorch, JAX & Keras 3

The Multi-Framework Landscape

The deep learning landscape has evolved significantly. While TensorFlow initially dominated with static graphs, PyTorch brought the eager execution revolution, and JAX introduced highly optimized functional transformations.

PyTorch, TensorFlow, and JAX

  • PyTorch: Known for its Pythonic, imperative style and dynamic computational graphs.
  • TensorFlow: An expansive ecosystem prioritizing scalable production deployment.
  • JAX: Focused on composable functional transformations (jax.grad, jax.jit, jax.vmap) on NumPy-like arrays.
Keras 3 Multi-Backend Architecture

Keras 3 allows you to write models once and run them on PyTorch, TensorFlow, or JAX transparently using the keras.ops module, which mirrors the NumPy API but works across all three backends.

Writing Backend-Agnostic Custom Layers

By using keras.ops instead of backend-specific operations (like tf.matmul or torch.matmul), your custom layers become universally compatible.

python 
import keras
from keras import layers
import keras.ops as ops

class CustomAttentionLayer(layers.Layer):
    def __init__(self, units, **kwargs):
        super().__init__(**kwargs)
        self.units = units

    def build(self, input_shape):
        dim = input_shape[-1]
        self.W_q = self.add_weight(shape=(dim, self.units), initializer="glorot_uniform", name="W_q")
        self.W_k = self.add_weight(shape=(dim, self.units), initializer="glorot_uniform", name="W_k")
        self.W_v = self.add_weight(shape=(dim, self.units), initializer="glorot_uniform", name="W_v")

    def call(self, inputs):
        # inputs shape: (batch_size, sequence_length, dim)
        q = ops.matmul(inputs, self.W_q)
        k = ops.matmul(inputs, self.W_k)
        v = ops.matmul(inputs, self.W_v)
        
        scores = ops.matmul(q, ops.transpose(k, axes=(0, 2, 1)))
        scores = scores / ops.sqrt(ops.cast(self.units, "float32"))
        
        weights = ops.softmax(scores, axis=-1)
        output = ops.matmul(weights, v)
        return output

# This layer can now be used with OS backend set to "torch", "jax", or "tensorflow"!
