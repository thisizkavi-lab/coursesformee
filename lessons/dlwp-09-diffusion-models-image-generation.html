1. Diffusion Models

Diffusion models construct images by learning to denoise pure noise over multiple steps.

Forward & Reverse Diffusion
---------------------------
Data x_0 -> Add Noise -> ... -> Add Noise -> Pure Noise x_T
Pure Noise x_T -> Denoise U-Net -> ... -> Denoise U-Net -> Data x_0

2. Code Walkthrough: VAE Reparameterization Trick

To backpropagate through stochastic nodes in a VAE, we use the reparameterization trick.


import keras
import tensorflow as tf

class Sampling(keras.layers.Layer):
    """Uses (z_mean, z_log_var) to sample z, the vector encoding a digit."""
    def call(self, inputs):
        z_mean, z_log_var = inputs
        batch = tf.shape(z_mean)[0]
        dim = tf.shape(z_mean)[1]
        epsilon = tf.random.normal(shape=(batch, dim))
        return z_mean + tf.exp(0.5 * z_log_var) * epsilon

Why do we add KL-divergence to the loss of a VAE?

Reveal Step-by-Step Solution

It acts as a regularizer, forcing the latent space distributions to match a standard normal distribution, ensuring the space is continuous and can be sampled from.
