Chapter 08: Super-Resolution Imaging & Localization Microscopy

Reading Time: 45 mins | Part III

Overcoming Abbe's Limit

The diffraction limit of light restricts optical resolution to ~250 nm. PALM/STORM techniques bypass this by sparsely activating fluorescent molecules so their diffraction blur (Point Spread Function, PSF) doesn't overlap. We then computationally localize the exact center of each emitter with nanometer precision.

Deep Mental Model: Point Spread Function Fitting

Instead of treating a pixel as the location, we view the bright patch as a 2D probability distribution and find its exact continuous center via Maximum Likelihood Estimation.

Algorithmic Implementation: Gaussian MLE Localization

Using SciPy to fit a 2D Gaussian to a fluorescent spot.

python 
import numpy as np
from scipy.optimize import curve_fit

def gaussian_2d(coords, amplitude, xo, yo, sigma_x, sigma_y, offset):
    x, y = coords
    xo = float(xo)
    yo = float(yo)
    g = offset + amplitude * np.exp(
        -(((x - xo)**2) / (2 * sigma_x**2) + ((y - yo)**2) / (2 * sigma_y**2))
    )
    return g.ravel()

# Generate a synthetic fluorescent spot
x = np.linspace(0, 10, 11)
y = np.linspace(0, 10, 11)
x, y = np.meshgrid(x, y)
true_params = [100, 5.2, 4.8, 1.0, 1.0, 10] 
data = gaussian_2d((x, y), *true_params) + np.random.normal(0, 5, 121)

# Fit the data
initial_guess = [90, 5, 5, 1, 1, 0]
popt, _ = curve_fit(gaussian_2d, (x, y), data, p0=initial_guess)

print(f"True location: X={true_params[1]}, Y={true_params[2]}")
print(f"Fitted location: X={popt[1]:.2f}, Y={popt[2]:.2f}")
python 
True location: X=5.2, Y=4.8
Fitted location: X=5.19, Y=4.81
