Chapter 01: Biomolecular Simulation & Allosteric Modulation

Reading Time: 45 mins | Part III

Microsecond to Millisecond All-Atom Simulations

In Stanford CS371, we explore the frontiers of computational biology by tracking atoms across time. Standard simulations historically captured only nanoseconds of biological time. Today, specialized architectures allow us to access the microsecond to millisecond timescale, where critical biological processes—like protein folding and allosteric modulation—actually occur.

G-protein-coupled receptors (GPCRs) are one of the most prominent drug targets. While traditional orthosteric drugs bind to the primary active site, allosteric modulators bind elsewhere, subtly altering the receptor's conformational landscape. Understanding this requires massive simulations and sophisticated change-point detection to identify metastable states.

Deep Mental Model: Markov State Models (MSMs)

Think of protein conformations as valleys in a vast, high-dimensional energy landscape. The protein spends most of its time vibrating in a valley (a metastable state) before occasionally surmounting a ridge (transition state) to fall into another valley.

Deep Dive: By simulating thousands of short trajectories and identifying transition probabilities, we can construct an MSM that accurately captures millisecond dynamics without requiring a single continuous millisecond-long simulation.

Algorithmic Implementation: Change-Point Detection

How do we identify when a protein jumps between states? We use change-point detection algorithms on the time-series of atomic distances.

import numpy as np
from scipy import signal

def detect_conformational_changes(distance_timeseries, penalty=10):
    """
    Uses a simple gradient and thresholding approach to find change points
    in a 1D trajectory (e.g., a critical inter-residue distance).
    """
    # Calculate the gradient of the smoothed time series
    smoothed = signal.savgol_filter(distance_timeseries, window_length=51, polyorder=3)
    gradient = np.abs(np.gradient(smoothed))
    
    # Identify peaks in the gradient (rapid changes)
    peaks, _ = signal.find_peaks(gradient, height=penalty)
    return peaks

# Simulated distance between Transmembrane Helix 3 and 6 in a GPCR
time_steps = np.linspace(0, 1000, 10000)
distances = np.piecewise(time_steps, 
                         [time_steps < 300, (time_steps >= 300) & (time_steps < 700), time_steps >= 700], 
                         [10.0, 14.5, 9.8]) 
distances += np.random.normal(0, 0.5, 10000) # add thermal noise

change_points = detect_conformational_changes(distances, penalty=0.1)
print(f"Conformational shifts detected at indices: {change_points}")

Exercise: Building a Transition Matrix

Given an array of discrete state assignments for a simulation trajectory `states = [0, 0, 1, 1, 1, 2, 0]`, write a function to compute the empirical transition probability matrix.

Reveal Step-by-Step Solution

Initialize an N x N matrix with zeros. Iterate through the trajectory pairs `(states[i], states[i+1])` and increment the corresponding matrix cell. Finally, normalize each row so it sums to 1. Handle rows with zero transitions to avoid division by zero.
