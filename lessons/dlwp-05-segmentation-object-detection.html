Chapter 05: Advanced Vision: Semantic Segmentation (U-Net) & Detection

Semantic Segmentation and U-Net

Semantic segmentation involves predicting a class label for every individual pixel in an image. The U-Net architecture is a widely used encoder-decoder network that excels at this task by concatenating high-resolution features from the encoder with upsampled features in the decoder.

import keras
from keras import layers

def get_unet(img_size, num_classes):
    inputs = keras.Input(shape=img_size + (3,))
    
    # Encoder (Contracting Path)
    x = layers.Conv2D(64, 3, padding="same", activation="relu")(inputs)
    x = layers.Conv2D(64, 3, padding="same", activation="relu")(x)
    skip1 = x
    x = layers.MaxPooling2D(2, strides=2)(x)
    
    x = layers.Conv2D(128, 3, padding="same", activation="relu")(x)
    x = layers.Conv2D(128, 3, padding="same", activation="relu")(x)
    skip2 = x
    x = layers.MaxPooling2D(2, strides=2)(x)
    
    # Bottleneck
    x = layers.Conv2D(256, 3, padding="same", activation="relu")(x)
    
    # Decoder (Expanding Path)
    x = layers.Conv2DTranspose(128, 2, strides=2, padding="same")(x)
    x = layers.Concatenate()([x, skip2])
    x = layers.Conv2D(128, 3, padding="same", activation="relu")(x)
    
    x = layers.Conv2DTranspose(64, 2, strides=2, padding="same")(x)
    x = layers.Concatenate()([x, skip1])
    x = layers.Conv2D(64, 3, padding="same", activation="relu")(x)
    
    # Output layer
    outputs = layers.Conv2D(num_classes, 3, activation="softmax", padding="same")(x)
    
    model = keras.Model(inputs, outputs)
    return model

Object Detection Foundations

Object detection outputs both bounding boxes and class labels. Key concepts include:

  • Anchor Boxes: Pre-defined boxes of various aspect ratios serving as priors.
  • IoU (Intersection over Union): Metric to measure the overlap between a predicted box and the ground truth.
  • NMS (Non-Maximum Suppression): Algorithm to filter out duplicate bounding box predictions.
