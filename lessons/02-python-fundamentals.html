Chapter 02: Python Fundamentals & The Memory Box Model

Transition from Karel

While Karel operates in a physical grid, Python manipulates data in memory. The transition marks a shift from spatial reasoning to abstract data processing.

Variables as Labeled References

In Python, variables are not boxes that hold values; they are labels attached to objects in memory. The "Memory Box Model" helps visualize this.

 x ---> [ 42 ]
 y ---> [ 42 ]
 (x and y reference the same integer object)

Fundamental Data Types

Python's core types include arbitrary precision integers (int), IEEE 754 floats (float), unicode strings (str), and booleans (bool).

Arithmetic Expressions

python

x = 10 / 3   # 3.3333333333333335 (true division)
y = 10 // 3  # 3 (floor division)
z = 10 % 3   # 1 (modulus)
Floating Point Pitfall: Due to IEEE 754, 0.1 + 0.2 != 0.3 exactly. Never use == for floats!

Formatted Console I/O

F-strings provide an elegant way to format output.

python

pi = 3.14159
print(f"Pi rounded to 2 decimals is {pi:.2f}")
python
Pi rounded to 2 decimals is 3.14

Exercise 1: Compute Interest

Write a program that takes a principal amount and interest rate, and prints the balance after 1 year.

Reveal Step-by-Step Solution
python

principal = float(input("Enter principal: "))
rate = float(input("Enter rate (as decimal): "))
balance = principal * (1 + rate)
print(f"New balance: ${balance:.2f}")
