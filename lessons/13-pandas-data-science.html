Chapter 04: Tabular Data Science & Engineering with Pandas

1. The Pandas Architecture: Series and DataFrames

In NumPy, we worked with homogeneous arrays of numerical data. But real-world data is messy, tabular, and heterogeneous—mixing strings, dates, integers, and floats. Enter Pandas. Pandas provides two foundational data structures: the 1D Series and the 2D DataFrame. Both are built on top of NumPy, but they introduce the concept of an Index—explicit labels for rows and columns.

Pandas DataFrame Memory Model
+-------+-------------------+-------------------+-------------------+
| Index | Column A (int64)  | Column B (float)  | Column C (object) |
+-------+-------------------+-------------------+-------------------+
|   0   |        42         |       3.14        |      "Apple"      |
|   1   |        17         |       2.71        |      "Banana"     |
|   2   |        99         |       1.41        |      "Cherry"     |
+-------+-------------------+-------------------+-------------------+
 ^^^     ^^^ Each column is a Pandas Series (wrapping a NumPy array)
 Explicit Row Labels

2. Data Ingestion & Export

Getting data in and out of Pandas is often a single line of code. The workhorse function is pd.read_csv().

python 
import pandas as pd

# Ingestion: parsing dates and setting an index
df = pd.read_csv("data.csv", sep=",", parse_dates=["timestamp"], index_col="id")

# Export
df.to_csv("cleaned_data.csv")

3. Exploratory Data Analysis (EDA)

Before modifying data, we must understand its shape and structure.

  • df.head() / df.tail(): View top/bottom rows.
  • df.info(): Memory usage, column dtypes, and non-null counts.
  • df.describe(): Summary statistics for numerical columns.
  • df.value_counts(): Frequency counts for categorical columns.

4. Indexing & Slicing Mechanics: .loc vs .iloc

Pandas distinguishes between implicit positional indexing (like Python lists) and explicit label indexing (like Python dictionaries).

Warning: Never use bracket slicing df[0:5] for rows unless you are exploring. Always use .loc (labels) or .iloc (integer positions) to avoid ambiguity.
python 
# Position-based (rows 0, 1, 2; cols 0, 1)
df.iloc[0:3, 0:2]

# Label-based (rows 'A' to 'C'; columns 'Age' and 'Salary')
df.loc['A':'C', ['Age', 'Salary']]

# Boolean masking (conditional querying)
rich_and_young = df.loc[(df['Salary'] > 100000) & (df['Age'] < 30)]

5. Data Cleaning & Missing Values

Missing data is represented as NaN (Not a Number). You can detect nulls with .isna(), drop them with .dropna(), or impute them with .fillna().

python 
# Impute missing ages with the median age
median_age = df['Age'].median()
df['Age'] = df['Age'].fillna(median_age)

6. Split-Apply-Combine with GroupBy

The groupby operation is the cornerstone of data aggregation. It conceptually splits the data based on a key, applies a function to each group independently, and combines the results.

Split-Apply-Combine Process:
1. SPLIT: DataFrame -> [Group A], [Group B], [Group C]
2. APPLY: mean(Group A), mean(Group B), mean(Group C)
3. COMBINE: New DataFrame with index [A, B, C] and their respective means.
python 
# Average salary by department
dept_salaries = df.groupby('Department')['Salary'].mean()

# Multiple statistics
df.groupby('Department').agg({
    'Salary': ['mean', 'max'],
    'Employee_ID': 'count'
})

7. Relational Joins & Reshaping

Pandas mirrors SQL's relational join semantics via pd.merge().

python 
# Inner Join
pd.merge(employees, departments, on="dept_id", how="inner")
Tip: Use pd.concat() to glue DataFrames vertically or horizontally when they don't have a relational link but share index/column structure.

Exercise 1: Data Cleaning

Given a DataFrame of users with missing 'Age' and 'Income' columns, fill missing ages with the median age, and drop rows where 'Income' is missing.

Reveal Step-by-Step Solution
python 
# Solution
df['Age'] = df['Age'].fillna(df['Age'].median())
df = df.dropna(subset=['Income'])
