Chapter 03: Score-Based Diffusion Models & Reverse-Time SDEs

Course: MIT 6.S184 | Reading Time: 55 mins | Part: Advanced Generative AI

The Score Function

The score function is defined as the gradient of the log-probability density: $s(x) = \nabla_x \log p(x)$.

Vincent Denoising Score Matching

Matching scores directly is hard. Vincent (2011) showed that we can match the score of a perturbed distribution using conditional Gaussian scores:

$\nabla_{x_t} \log p(x_t|x_0) = -\frac{x_t - \mu_t}{\sigma_t^2}$

Reverse-Time SDE (Anderson)
For any forward SDE $dx = f(x,t)dt + g(t)dw$, there exists a reverse-time SDE:
$dx = [f(x,t) - g(t)^2 \nabla_x \log p_t(x)]dt + g(t)d\bar{w}$ 
import torch

def dsm_loss(score_model, x_0, t, sigma_t):
    noise = torch.randn_like(x_0)
    x_t = x_0 + sigma_t * noise
    
    target_score = -noise / sigma_t
    predicted_score = score_model(x_t, t)
    
    return torch.mean((predicted_score - target_score)**2)
