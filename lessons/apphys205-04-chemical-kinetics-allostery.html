Chapter 04: Chemical Kinetics, Cooperativity & Allosteric Transitions

1. Mass Action & Binding Isotherms

At the core of cellular computation is molecular binding. For a receptor $R$ binding a ligand $L$ to form a complex $RL$, the law of mass action dictates that the equilibrium dissociation constant is $K_D = \frac{[R][L]}{[RL]}$. The fractional occupancy of the receptor is represented by a simple Langmuir binding isotherm:

$$ p_{bound} = \frac{[L]}{K_D + [L]} $$

2. Cooperativity and the Hill Equation

Biological systems often exhibit switch-like behavior. If a protein has multiple binding sites, the binding of one ligand can increase the affinity of the remaining sites. This is cooperativity, phenomenologically described by the Hill Equation:

$$ p_{bound} = \frac{[L]^n}{K_D^n + [L]^n} $$

Where $n$ is the Hill coefficient. A higher $n$ results in a steeper, more digital "switch" in response to ligand concentration.

3. The MWC Allosteric Model

The Hill equation is empirical. The Monod-Wyman-Changeux (MWC) model provides a physical basis for cooperativity. It postulates two global conformational states for a multi-subunit protein: Tense (T, low affinity) and Relaxed (R, high affinity). The binding sites are assumed to be independent within each state, but the entire protein must transition in a concerted fashion.

Gene Regulation Analogy:

These thermodynamic binding models are extensively used to predict gene transcription rates based on the concentrations of transcription factor proteins binding to promoter regions of DNA. Activation and repression act as allosteric modulators on the probability of RNA Polymerase binding.

4. Comparing Binding Models in Python

Let's write code to compute and visualize these different models.

python 
import numpy as np

def langmuir_binding(L, Kd):
    return L / (Kd + L)

def hill_binding(L, Kd, n):
    return (L**n) / (Kd**n + L**n)

def mwc_binding(L, L_allosteric, Kr, Kt, num_sites=4):
    """
    MWC model for fractional occupancy.
    L_allosteric: Equilibrium constant for T <-> R transition without ligand [T]/[R]
    Kr, Kt: Dissociation constants for R and T states.
    """
    alpha = L / Kr
    c = Kr / Kt  # typically c < 1 (T state binds weakly)
    
    numerator = alpha * (1 + alpha)**(num_sites - 1) + L_allosteric * c * alpha * (1 + c*alpha)**(num_sites - 1)
    denominator = (1 + alpha)**num_sites + L_allosteric * (1 + c*alpha)**num_sites
    return numerator / denominator

concentrations = np.array([0.1, 1, 10, 100])
Kd = 10.0

print("Ligand | Langmuir | Hill (n=4) | MWC (4 sites)")
for c in concentrations:
    lang = langmuir_binding(c, Kd)
    hill = hill_binding(c, Kd, n=4)
    mwc = mwc_binding(c, L_allosteric=1000, Kr=1, Kt=100, num_sites=4)
    print(f"{c:6.1f} | {lang:8.4f} | {hill:10.4f} | {mwc:13.4f}")
