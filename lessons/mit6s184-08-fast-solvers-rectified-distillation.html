Chapter 08: Fast Solvers, Rectified Flow & Few-Step Distillation

Numerical ODE Solvers for Fast Sampling

In Flow Matching and Diffusion Models, inference relies on solving an Ordinary Differential Equation (ODE). Traditional Euler methods require hundreds of steps. Modern methods employ higher-order numerical ODE solvers: adaptive Runge-Kutta 4/5, Heun's 2nd order method, and specialized exponential integrators like DPM-Solver or UniPC. These reduce step counts from 1000 down to 10-20 with minimal quality loss.

Rectified Flow & The "Reflow" Algorithm

Introduced by Liu et al., Rectified Flow straightens the trajectories mapping noise to data. The Reflow algorithm recursively trains on $(x_0, x_1)$ pairs generated by a previously trained model. By repeatedly matching the synthetic pairs, the velocity field becomes increasingly straight, enabling reliable 1-step generation.

Other real-time generation techniques include Progressive Distillation (Salimans & Ho), Consistency Models (Song et al.), and Score Distillation Sampling (SDS). These frameworks successfully compress massive generation steps into 1-4 step real-time generation suitable for production deployments.

Code: 2-Rectified Flow "Reflow" Process

python 

import torch

def generate_synthetic_pairs(model_1, noise_samples, num_steps=20):
    """
    Use the 1-Rectified Flow model to generate data from noise.
    These pairs will be used to train the 2-Rectified Flow model.
    """
    dt = 1.0 / num_steps
    x_t = noise_samples.clone()
    
    # Simple Euler ODE solver for synthesis
    for step in range(num_steps):
        t = torch.ones(x_t.size(0), 1) * (step * dt)
        t = t.to(x_t.device)
        v = model_1(x_t, t)
        x_t = x_t + v * dt
        
    return noise_samples, x_t  # Returns (x0, x1) pairs

def train_reflow_step(model_2, x0_synth, x1_synth):
    """
    Train the 2-Rectified flow model on the synthetic straight paths.
    """
    t = torch.rand(x0_synth.size(0), 1, device=x0_synth.device)
    
    # Straight line interpolation
    x_t = (1 - t) * x0_synth + t * x1_synth
    
    # Target is straight vector from synth_noise to synth_data
    v_target = x1_synth - x0_synth
    
    v_pred = model_2(x_t, t)
    return torch.nn.functional.mse_loss(v_pred, v_target)
