Chapter 08: Object-Oriented Architecture & Special Methods

The Object-Oriented Paradigm

Object-Oriented Programming (OOP) allows us to bundle data (state) and functions (behavior) into unified concepts called Objects. A Class acts as a blueprint, and an Object is a specific instantiation of that blueprint.

Blueprint (Class: BankAccount)
  State: balance
  Behavior: deposit(), withdraw()

Instance A (Object)          Instance B (Object)
  balance = 100                balance = 5000

The Constructor and self

The __init__ method initializes a new object's state. The self parameter is a reference to the specific instance being created or manipulated. When you call obj.method(), Python implicitly translates it to Class.method(obj).

python
class BankAccount:
    def __init__(self, initial_balance):
        self.balance = initial_balance  # Instance variable
        
    def deposit(self, amount):
        self.balance += amount

Dunder (Magic) Methods

Double-underscore methods (dunders) allow custom classes to integrate deeply with Python's built-in operators and functions.

  • __str__(self): User-friendly string representation (called by print() or str()).
  • __repr__(self): Unambiguous representation, ideally a valid Python expression.
  • __add__(self, other): Allows using the + operator.
  • __eq__(self, other): Allows using the == operator.

Case Study: A Fraction Class

Let's implement a Fraction class that automatically reduces itself and supports addition.

python
import math

class Fraction:
    def __init__(self, num, den):
        gcd = math.gcd(num, den)
        self.num = num // gcd
        self.den = den // gcd
        
    def __str__(self):
        return f"{self.num}/{self.den}"
        
    def __add__(self, other):
        new_num = self.num * other.den + other.num * self.den
        new_den = self.den * other.den
        return Fraction(new_num, new_den)

Practical Exercises

Exercise 1: Bajillion Class

Create a class that behaves like an arbitrary precision integer.

Reveal Step-by-Step Solution
python
class Bajillion:
    def __init__(self, digits):
        # Store as list of ints for simplicity
        self.digits = [int(d) for d in digits]
        
    def __str__(self):
        return "".join(str(d) for d in self.digits)
