Chapter 08: Biological Information, Sensing & Bacterial Chemotaxis

1. Biological Information Processing

Living systems must extract information from noisy environments. Concepts from Shannon's Information Theory—such as Entropy $H = -\sum p \log_2 p$ and Mutual Information $I(X;Y)$—are powerfully applied to determine the channel capacity of biological signaling networks.

2. E. coli Run-and-Tumble Chemotaxis

E. coli is too small to measure spatial chemical gradients across its body length (the noise from diffusion swamps the signal). Instead, Berg and Brown (1972) discovered it uses a temporal comparison. It records the concentration now, compares it to the concentration a few seconds ago, and biases a random walk based on the derivative.

The movement consists of straight "runs" and randomized "tumbles". If the cell senses life is getting better (positive temporal derivative of attractant), it lowers the tumbling frequency, thereby lengthening the runs up the gradient.

Perfect Adaptation (Integral Feedback): To remain sensitive over a massive concentration range (from nM to mM), the receptor cluster undergoes biochemical methylation. This shifts the $K_D$ dynamically so the baseline tumbling rate always resets to exactly the same resting state, a feature mathematically equivalent to integral feedback control.

3. 2D Agent-Based Chemotaxis Simulation

We'll write a simplified 2D simulation showing a bacterium performing a biased random walk up an exponential gradient.

python 
import numpy as np

def run_chemotaxis_sim(steps=1000):
    # Field properties: C(x) = exp(x/100)
    def conc(x): return np.exp(x/100.0)
    
    pos = np.array([0.0, 0.0])
    angle = np.random.uniform(0, 2*np.pi)
    velocity = 20.0  # um/s
    dt = 0.1
    
    trajectory = [pos.copy()]
    memory_C = conc(pos[0]) # initial memory
    
    for _ in range(steps):
        current_C = conc(pos[0])
        dC_dt = (current_C - memory_C) / dt
        
        # Base tumble probability
        p_tumble = 0.1
        if dC_dt > 0:
            # Life is getting better, tumble less!
            p_tumble = 0.02
            
        if np.random.rand() < p_tumble:
            angle = np.random.uniform(0, 2*np.pi) # Tumble
            
        # Run
        pos[0] += velocity * np.cos(angle) * dt
        pos[1] += velocity * np.sin(angle) * dt
        
        memory_C = current_C # update memory
        trajectory.append(pos.copy())
        
    return np.array(trajectory)

traj = run_chemotaxis_sim(steps=500)
print(f"Start pos: ({traj[0,0]:.1f}, {traj[0,1]:.1f})")
print(f"End pos:   ({traj[-1,0]:.1f}, {traj[-1,1]:.1f})")
print("Net motion should bias strongly toward +X axis (higher nutrient).")
