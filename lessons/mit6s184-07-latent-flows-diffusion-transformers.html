Chapter 07: Latent Flow Matching, DiT & Multimodal Architectures

High-Resolution Computational Scaling

Operating directly in pixel space is computationally prohibitive for high-resolution images. Modern architectures employ Autoencoders with KL regularization (VAEs) to achieve spatial compression (typically $8\times$ to $16\times$). The generative modeling is then performed in this compressed, lower-dimensional "latent space" (Latent Flow Matching), as seen in Stable Diffusion 3 and FLUX architectures.

Diffusion Transformers (DiT)

Pioneered by Peebles & Xie, the Diffusion Transformer (DiT) replaces the traditional U-Net with a Vision Transformer (ViT) architecture. Instead of spatial convolutions, the latent image is split into patches. Crucially, DiT incorporates AdaLN-Zero (Adaptive LayerNorm) blocks, which adaptively inject conditioning signals (timestep $t$ and label/prompt embedding $c$) into the transformer blocks without breaking the standard Transformer architecture.

DiT Block with AdaLN-Zero Architecture

      [ Input Latent Patches ]
                 |
          +-------------+      [ c, t Embeddings ]
          | AdaLN-Zero  | <----------|
          +-------------+            | MLP
                 |                   | (Predicts scale, shift, gate)
        [ Self-Attention ]           |
                 |                   |
            [ Gate 1 ] <-------------|
                 |
          +-------------+            |
          | AdaLN-Zero  | <----------|
          +-------------+
                 |
        [ MLP / Feed Forward ]
                 |
            [ Gate 2 ] <-------------|
                 |
           [ Output ]

Code: DiT Block in PyTorch

python

import torch
import torch.nn as nn

class AdaLNZero(nn.Module):
    def __init__(self, emb_dim, hidden_dim):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.SiLU(),
            nn.Linear(emb_dim, 6 * hidden_dim) # 6 parameters: shift/scale/gate for 2 blocks
        )
        
    def forward(self, x, c):
        # c is combined time+context embedding
        params = self.mlp(c).unsqueeze(1) # shape: (B, 1, 6*hidden)
        (shift_msa, scale_msa, gate_msa, 
         shift_mlp, scale_mlp, gate_mlp) = params.chunk(6, dim=-1)
        return shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp

class DiTBlock(nn.Module):
    def __init__(self, hidden_dim, emb_dim, num_heads):
        super().__init__()
        self.norm1 = nn.LayerNorm(hidden_dim, elementwise_affine=False)
        self.attn = nn.MultiheadAttention(hidden_dim, num_heads, batch_first=True)
        self.norm2 = nn.LayerNorm(hidden_dim, elementwise_affine=False)
        self.mlp = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim * 4),
            nn.GELU(),
            nn.Linear(hidden_dim * 4, hidden_dim)
        )
        self.adaln = AdaLNZero(emb_dim, hidden_dim)
        
    def forward(self, x, c):
        shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp = self.adaln(x, c)
        
        # Self Attention with AdaLN
        norm_x = self.norm1(x) * (1 + scale_msa) + shift_msa
        attn_out, _ = self.attn(norm_x, norm_x, norm_x)
        x = x + gate_msa * attn_out
        
        # MLP with AdaLN
        norm_x = self.norm2(x) * (1 + scale_mlp) + shift_mlp
        mlp_out = self.mlp(norm_x)
        x = x + gate_mlp * mlp_out
        
        return x
