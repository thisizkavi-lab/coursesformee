Chapter 07: Electrophysiology & The Hodgkin-Huxley Action Potential

1. The Equivalent Circuit Model of the Membrane

The lipid bilayer acts as a remarkably good insulator, providing a membrane capacitance of $C_m \approx 1 \text{ }\mu\text{F/cm}^2$. Embedded in this membrane are ion channels that act as variable resistors (conductances). The Nernst potential equations set the "battery" voltages for different ion species based on their concentration gradients (e.g., $E_K \approx -77 \text{ mV}$, $E_{Na} \approx +50 \text{ mV}$).

The total membrane voltage dynamics are governed by Kirchhoff's current law:

$$ C_m \frac{dV}{dt} = I_{ext} - (I_{Na} + I_K + I_{leak}) $$

2. The Hodgkin-Huxley Model

In 1952, Hodgkin and Huxley modeled the voltage-dependent gating of Sodium and Potassium channels in the squid giant axon using three dimensionless probability variables: $m$ (Na activation), $h$ (Na inactivation), and $n$ (K activation). The macroscopic currents are:

$$ I_{Na} = \bar{g}_{Na} m^3 h (V - E_{Na}) $$

$$ I_K = \bar{g}_K n^4 (V - E_K) $$

Nonlinear Dynamics: The differential equations for $V, m, h, n$ are highly nonlinear. A small depolarizing current can trigger a runaway positive feedback loop where $V$ rises, increasing $m$, increasing $I_{Na}$, further increasing $V$. This creates the sharp rising phase of the action potential.

3. Numerical Integration of HH Equations

Because the Hodgkin-Huxley equations are a system of non-linear ODEs, we solve them numerically using SciPy's odeint.

python 
import numpy as np
from scipy.integrate import odeint

# Constants (mS/cm^2, mV, uF/cm^2)
C_m = 1.0
g_Na = 120.0
g_K = 36.0
g_L = 0.3
E_Na = 50.0
E_K = -77.0
E_L = -54.387

def hh_deriv(y, t, I_ext):
    V, m, h, n = y
    
    # Alpha and Beta functions for gating variables
    alpha_m = 0.1 * (V + 40.0) / (1.0 - np.exp(-(V + 40.0) / 10.0))
    beta_m  = 4.0 * np.exp(-(V + 65.0) / 18.0)
    alpha_h = 0.07 * np.exp(-(V + 65.0) / 20.0)
    beta_h  = 1.0 / (1.0 + np.exp(-(V + 35.0) / 10.0))
    alpha_n = 0.01 * (V + 55.0) / (1.0 - np.exp(-(V + 55.0) / 10.0))
    beta_n  = 0.125 * np.exp(-(V + 65.0) / 80.0)
    
    # Currents
    I_Na = g_Na * (m**3) * h * (V - E_Na)
    I_K = g_K * (n**4) * (V - E_K)
    I_L = g_L * (V - E_L)
    
    dVdt = (I_ext - (I_Na + I_K + I_L)) / C_m
    dmdt = alpha_m * (1 - m) - beta_m * m
    dhdt = alpha_h * (1 - h) - beta_h * h
    dndt = alpha_n * (1 - n) - beta_n * n
    
    return [dVdt, dmdt, dhdt, dndt]

# Time array
t = np.arange(0.0, 50.0, 0.01)

# Current injection (e.g., 10 uA/cm^2 from t=10 to t=40)
def I_inj(t):
    return 10.0 if 10.0 <= t <= 40.0 else 0.0

Exercise: The Refractory Period

Modify the HH simulation to inject two rapid current pulses separated by 5 ms. Observe how the second pulse fails to elicit a spike. Which gating variable ($m, h,$ or $n$) is primarily responsible for the absolute refractory period?

Reveal Step-by-Step Solution

The variable $h$ (sodium channel inactivation). During the peak of the action potential, $h$ drops near zero and takes several milliseconds to recover after the voltage returns to rest. Without recovered sodium channels, another spike is impossible.
