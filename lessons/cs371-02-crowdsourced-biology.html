Chapter 02: Citizen Computing: Video Games for Molecular Design

Reading Time: 45 mins | Part III

Gamification in Scientific Discovery

Automated algorithms excel at rapid local optimization, but human intuition remains unparalleled at navigating complex spatial topologies. By framing molecular design as a puzzle, projects like Foldit and EteRNA have crowdsourced solutions to protein folding and RNA design, often outperforming automated methods.

Deep Mental Model: Human Intuition vs. Monte Carlo Sampling

While an algorithm might blindly sample the local energy landscape via Monte Carlo methods, humans utilize global spatial planning, identifying large-scale topological shifts that algorithms struggle to cross.

Algorithmic Implementation: RNA Secondary Structure (Nussinov)

Before designing RNA, we must predict how a sequence folds. The Nussinov dynamic programming algorithm predicts the secondary structure by maximizing base-pair matching.

import numpy as np

def nussinov(sequence):
    """
    Dynamic programming to find the maximum number of base pairs in an RNA sequence.
    Valid pairs: A-U, C-G.
    """
    n = len(sequence)
    dp = np.zeros((n, n))
    
    def is_pair(base1, base2):
        pairs = {('A', 'U'), ('U', 'A'), ('C', 'G'), ('G', 'C')}
        return (base1, base2) in pairs

    for length in range(1, n):
        for i in range(n - length):
            j = i + length
            # Case 1: i and j are paired
            if is_pair(sequence[i], sequence[j]):
                dp[i][j] = dp[i+1][j-1] + 1
            # Case 2: i and j are not paired
            dp[i][j] = max(dp[i][j], dp[i+1][j], dp[i][j-1])
            # Case 3: Bifurcation
            for k in range(i+1, j):
                dp[i][j] = max(dp[i][j], dp[i][k] + dp[k+1][j])
                
    return dp[0][n-1]

seq = "GCACG"
max_pairs = nussinov(seq)
print(f"Maximum base pairs for {seq}: {max_pairs}")
