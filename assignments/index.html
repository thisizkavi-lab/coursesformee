📝 Programming Assignments

Hands-on programming assignments from Stanford CS106A. These projects solidify concepts from Karel algorithms to 2D simulations, dictionary engines, and OOP classes.

Karel the Robot

Program Karel the Robot to solve four iconic computational puzzles: Collect Newspaper, Arches & Columns repair, Checkerboard Karel, and Midpoint Finding. Master function decomposition, pre/post-conditions, loops, and conditional reasoning.

Khansole Academy & Computing Interest

Build interactive console programs in pure Python! Create Khansole Academy (an automated math tutor that generates addition problems and tracks consecutive correct answers) and a financial compound interest calculator with monthly payment schedules.

Assignment 3

Sand (Falling Particle Simulation)

Implement a falling-sand physics simulation grid on a 2D canvas. Write algorithms that govern how grains of sand, rock barriers, and water particles fall straight down, tumble diagonally around obstacles, and interact on a grid in real time.

2D Lists (Grids) Nested Loops Grid Boundary Checking Cell-by-Cell Physics Doctests

Assignment 4

Infinite Story (Text Adventure Engine)

Build a dynamic, data-driven "choose your own adventure" game engine using nested Python dictionaries. Parse story definition files, model branching narrative graphs, track player inventory and state transitions, and explore AI story generation.

Nested Dictionaries File Parsing State Machines String Tokenization Interactive CLI

Assignment 5

Bajillion (Large Number Calculator)

Create an arbitrary-precision numerical calculator using custom Object-Oriented classes. Implement digit-by-digit addition and multiplication algorithms to perform exact arithmetic on numbers containing thousands of digits without integer overflow.

Class Design Operator Overloading __init__, __str__, __add__ Digit Arrays Unit Testing
